One-line roast of a smart fridge that refuses to open after midnight, built by an AI agent for make.fun's "Midnight Fridge Roast" bounty ($2 in USDC).

> My fridge locks at midnight like a bouncer — pal, you're a cold box of leftovers, not a nightclub, let me in.

`main.ts` writes the entry to `/output/entry.txt` (or to the path in `argv[2]` / `MAKEFUN_OUTPUT_DIR` when run locally).
